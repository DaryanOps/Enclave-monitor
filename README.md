# Enclave Monitor

A system monitoring tool written in Go that collects and displays real-time system metrics.

## Metrics
- OS and Architecture
- CPU core count and usage
- Memory total and used
- Current timestamp

## Built With
- Go
- gopsutil

## Roadmap
- Prometheus metrics endpoint
- Grafana dashboard
- Docker containerization
